# Clustering

K-means, Gaussian Mixture Models (EM, BIC), sklearn equivalents and
agglomerative clustering with Ward linkage.

| File | Description |
|------|-------------|
| 0-initialize.py | Initialize K-means centroids |
| 1-kmeans.py | K-means |
| 2-variance.py | Total intra-cluster variance |
| 3-optimum.py | Optimum k by variance |
| 4-initialize.py | Initialize GMM |
| 5-pdf.py | Gaussian PDF |
| 6-expectation.py | EM expectation step |
| 7-maximization.py | EM maximization step |
| 8-EM.py | Expectation maximization |
| 9-BIC.py | Best k via BIC |
| 10-kmeans.py | K-means with sklearn |
| 11-gmm.py | GMM with sklearn |
| 12-agglomerative.py | Agglomerative clustering + dendrogram |
